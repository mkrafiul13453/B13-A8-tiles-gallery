# TilesGallery

A modern and responsive tile showcase web application built with Next.js App Router. 
Users can browse different tiles, view detailed information, create accounts, log in securely, and manage their profile information.

## Features

- User Registration & Login
- Secure Authentication with BetterAuth
- MongoDB Database Integration
- View Tile Details
- Update User Profile Information
- Responsive Design for All Devices
- Modern UI with HeroUI / DaisyUI



## Technologies Used
### Frontend
- Next.js (App Router)
- React
- Tailwind CSS
- HeroUI / DaisyUI
- React Icons

### Backend & Authentication
- BetterAuth
- MongoDB
- MongoDB Adapter
